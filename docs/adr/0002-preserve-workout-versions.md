# Preserve workout versions and started sessions

The coach may add exercises and replace today's unstarted or future scheduled workouts automatically, using America/Los_Angeles calendar dates, but changed prescriptions become distinct named workout versions assigned to selected dates instead of editing shared definitions in place. Started sessions retain their starting prescription even when started offline; completed history is never a coach write target. Global form notes may be updated only through an explicit notes command, independently of workout-specific instructions.
